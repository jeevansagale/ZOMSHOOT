# ZOMSHOOT

A 2D zombie survival shooter built in **C++** using **Raylib**, where players fight off endless waves of zombies, earn points, and survive as long as possible.

**ZOMSHOOT** was one of my first major C++ game development projects, created during my first semester to explore real-time game programming, collision detection, animations, and gameplay mechanics.

## Features

* Shooting mechanics
* Health system

* Collision detection
* Sprite-based rendering
* Game Over screen
* Interactive menu system

---

## Gameplay

The objective is simple:

* Survive against waves of zombies.
* Eliminate enemies to increase your score.
* Avoid taking damage.
* Stay alive for as long as possible.

As the game progresses, surviving becomes increasingly difficult, encouraging faster reactions and better positioning.
