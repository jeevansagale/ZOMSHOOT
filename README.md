# 🧟‍♂️ ZOMSHOOT

A 2D zombie shooter game built in C++ using Raylib.
Now playable directly — no need to install Raylib or compile anything! 🎮

## 📸 Preview

## 📌 About

ZOMSHOOT is a small, fun 2D shooter game where you fight waves of zombies.
This project is made with Raylib, but you don’t need to worry about installing it — just download and run the game.

## 🚀 Features

* Player movement and shooting

* Zombie spawning and simple AI

* Collision detection

* Score system / HUD

* Fun 2D gameplay mechanics

* Quiz for reward system

## 🖥️ How to Play (Executable)
### 1️⃣ Download

Find the downloded folder
Extract the folder

### 2️⃣ Run

On Windows: Double-click FINAL LAUC PROJECT.exe

On Linux / Mac: Not compatible

No installation or setup required — just run and play! ✅

## 🕹️ Controls
**Action	Keys:**
* Move Left	A
* Move Right	D
* Shoot	Left Click
* Jump Space
